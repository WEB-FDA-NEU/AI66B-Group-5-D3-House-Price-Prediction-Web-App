# House Price Prediction Web App

## Project Title
House Price Prediction Web App

## Selected Topic
D3 – Machine Learning Prediction Web App: A web application where users input data (e.g., house features) and the app returns a prediction generated by a trained machine learning model.

## Main Features
- Web form for users to input house features (e.g., area, location, number of bedrooms/bathrooms, etc.)
- Backend API built with FastAPI to serve the trained ML model
- Input validation using Pydantic to ensure data integrity before inference
- Model packaging and loading for real-time inference within the FastAPI process
- Display of the predicted house price (with estimated confidence/range) to the user
